## 📌 Sobre o Projeto
Projeto 100% Frontend (Static/Hardcoded) desenvolvido para o escritório Fontenele Advogados. A arquitetura foi desenhada para ser escalável, limpa e com tipografia invertida (Serifa para títulos, Sans para corpo), focado em autoridade editorial e não como um sistema genérico.

## 🛠 Tecnologias
- **Framework:** React.js + Vite
- **Estilização:** Tailwind CSS v4
- **Ícones:** Lucide React
- **Micro-interações:** Motion

## 🚀 Como Executar Localmente
O projeto está encapsulado na pasta `frontend/` para suportar uma arquitetura monorepo no futuro.

1. Acesse a pasta do frontend:
   `cd frontend`

2. Instale as dependências:
   `npm install`

3. Inicie o servidor de desenvolvimento:
   `npm run dev`
